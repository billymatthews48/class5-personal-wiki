# Quantitative Methods

Billy's coursework in Quantitative Methods covered fundamental statistical concepts, including parameter estimation, hypothesis testing, and measures of central tendency. The course also explored advanced modelling techniques such as Monte Carlo simulation, regression analysis, and the application of machine learning algorithms to transform data into management actions.

## Key ideas
- Business statistics uses tools to convert data into information to aid in decision making. ([[raw/cambridge/Exams/MS2 Quantitative Methods/Lectures/Parameter estimation and hypothesis testing.docx|MS2 Quantitative Methods / Parameter estimation and hypothesis testing]])
- Monte Carlo simulation is a modelling approach used alongside static models and 'what if' analysis. ([[raw/cambridge/Exams/MS2 Quantitative Methods/Lectures/Monte Carlo simulation.docx|MS2 Quantitative Methods / Monte Carlo simulation]])
- Simple regression finds the relationship between two sets of variables, using a correlation coefficient to check reliability. ([[raw/cambridge/Exams/MS2 Quantitative Methods/Lectures/Simple and multiple regression.docx|MS2 Quantitative Methods / Simple and multiple regression]])
- Machine learning algorithms learn from past data to help transform data into management actions. ([[raw/cambridge/Exams/MS2 Quantitative Methods/Lectures/Machine learning.docx|MS2 Quantitative Methods / Machine learning]])
- Inference in statistics involves drawing conclusions about a population based on a sample. ([[raw/cambridge/Exams/MS2 Quantitative Methods/Lectures/Parameter estimation and hypothesis testing.docx|MS2 Quantitative Methods / Parameter estimation and hypothesis testing]])
- Supervised learning in machine learning requires input data that has observations with known labels. ([[raw/cambridge/Exams/MS2 Quantitative Methods/Lectures/Machine learning.docx|MS2 Quantitative Methods / Machine learning]])
